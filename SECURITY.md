# Security Policy

## Reporting a Vulnerability

If you discover a security issue in any **por-dgo** repository, please report it responsibly:

1. **Do not** open a public GitHub issue.
2. Email **giles.cooper@teledyne.com** with a description of the vulnerability.
3. Include steps to reproduce if possible.

You should receive an acknowledgment within **3 business days**.

## Scope

All repositories in this organization are internal tools that run on **localhost only** with no external network exposure. Authentication relies on Windows domain SSO — no credentials are stored in source code.

## Expectations

- All repositories in this organization are **private**. Do not change repository visibility without approval.
- Do not commit internal URLs, hostnames, IP addresses, credentials, or infrastructure details to any file.
- This is an **ITAR/CUI-sensitive environment**. Treat all project data accordingly.
