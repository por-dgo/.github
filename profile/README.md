# Teledyne DGO — Portsmouth

Internal tools and utilities developed at [Teledyne DGO](https://www.teledynemarine.com/brands/dgo), a [Teledyne Marine](https://www.teledynemarine.com/) company headquartered in Portsmouth, NH. Teledyne DGO (named for founder Donald G. O'Brien) specializes in high-reliability electrical interconnect systems — glass-to-metal sealed connectors, penetrators, and feedthrough systems for extreme environments.

## Projects

| Project | Description |
|---------|-------------|
| **IFS Silver Lining** | Supervisor dashboard for IFS Cloud shop orders, quality tracking, and OTD/FPY analytics |
| **IFS Breeze** | Operator portal for shop floor terminals |

## Tech Stack

- **Python 3.13** / Flask — backend
- **IFS Cloud 24R2** — enterprise ERP (OData v4 APIs)
- **PyInstaller** — single-file `.exe` packaging
- **Vanilla JS** — lightweight frontends, no framework dependencies

## About

These tools provide focused, fast access to IFS Cloud manufacturing data — shop order tracking, operation status, quality metrics — without navigating the full Aurena interface. Built for supervisors and operators on the shop floor.
